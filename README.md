# automatewarehouse.ai

Personal website of Naveen Chandra Kukkala. Static site served by GitHub Pages.

All files sit at the top level (no folders), so updates are a single drag-and-drop on GitHub's "Upload files" page.

- `index.html` — the home page (styles are inside the file)
- `headshot.jpg` — portrait
- `logo-*.png` — employer, university, credential and organization logos
- `sc2-*` — SC² Supply Chain Comics logo and strips
- `CNAME` — custom domain for GitHub Pages
- `404.html` — page shown for broken links

To update: replace or add files here and commit to `main`. GitHub Pages republishes in about a minute.
